Why Quantum Matters for Smart Contracts

Every DeFi protocol uses ECDSA signatures. Shor's algorithm — running on a sufficiently powerful quantum computer — breaks ECDSA in polynomial time. Not tomorrow. But not never, either.

NIST finalized three post-quantum standards in August 2024, with a fourth algorithm (FN-DSA/Falcon) selected for standardization:

  • FIPS 203: ML-KEM (Kyber) — lattice-based key exchange (finalized)
  • FIPS 204: ML-DSA (Dilithium) — lattice-based signatures (finalized)
  • FIPS 205: SLH-DSA (SPHINCS+) — hash-based signatures (finalized; provably secure if hashes hold)
  • FIPS 206: FN-DSA (Falcon) — lattice-based signatures, smallest signatures (666 bytes); FIPS pending

The math is sound. The implementations are not. Implementation vulnerabilities are documented in the primary literature for each:

  • Dilithium — public key compression leaks t₀; after ~200K signatures, a single power trace recovers the secret key with 9% success.
  • Kyber — KyberSlash division timing + CVE-2024-37880 (compiler-introduced branches in Clang ≤18.x). Full key recovery in minutes.
  • SLH-DSA — stateless by design; the real risk is RNG misuse during key generation.
  • Falcon — the SHIFT SNARE attack recovers the full secret key from a single power trace with 99.99% success. Dilithium's single-trace attack succeeds 9% of the time — Falcon's almost never fails.

Our audit tells you: Are you using quantum-vulnerable primitives today? What's the migration path?

Blockchain: PQC Is Already Running

This isn't theoretical anymore. Post-quantum signatures are live on production chains:

  • Algorand deployed native Falcon (FN-DSA) verification on mainnet in November 2025 — the first production post-quantum transaction on a major blockchain. Native Falcon accounts planned for Q3 2026.
  • Ethereum is on a concrete path: EIP-8052 (Falcon precompile, ~3,000 gas), EIP-8051 (ML-DSA precompile, 4,500 gas), EIP-8141 (frame transactions for account-level signature agility), and EIP-7851+8151 (irreversible ECDSA key deactivation). The Ethereum Foundation formed a dedicated Post-Quantum team in January 2026, targeting readiness by 2029.
  • The real target is Proof-of-Stake, not Proof-of-Work. PoW mining is embarrassingly parallel — Grover's speedup is cancelled. PoS validator keys (BLS on BLS12-381) are broken by Shor's algorithm. If your rollup uses BN254 or BLS12-381 pairing curves, those are quantum-vulnerable; STARKs (hash-based) are not.

You can't run PQC signatures on Ethereum L1 economically today (pure-Solidity Falcon costs 1.6M–24M gas). But you can build cryptographic agility now — EIP-4337 account abstraction or proxy patterns let you swap the verifier when precompiles ship.
